# MTR France GTNH Port Implementation Plan

> **For agentic workers:** Execute the independent tasks in this session using subagent-driven development. Root owns Java, Gradle and native launches and performs the final integration/review.

**Goal:** Deliver MTR France Addon V1.2.0 as a separate working Forge 1.7.10 addon for GTNH.

**Architecture:** Reuse the prepared RetrofuturaGradle project and MTR development JAR. Add native bootstrap/mixins, adapt common code, and stage validated resources without packaging MTR itself.

**Tech Stack:** JDK 21, Java 8 bytecode, RetrofuturaGradle 1.4.9, Forge 1.7.10, GTNH UniMixins, Python standard library asset checks.

**Spec:** `docs/superpowers/specs/2026-10-31-gtnh-port-design.md`

## Global Constraints

- Work in `work/france-addon-port/addon` and copied GTNH clients; preserve the original client.
- No reverse SSH forwarding, publication or GitHub push.
- Hidden native window and silent audio output; root owns every Java/Gradle/game launch.
- Keep source IDs and MIT credits; no embedded MTR, Core, mappings or UniMixins.

- English documentation and release descriptions.
